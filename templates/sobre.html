Micro SO para Microcontroladores en MicroPython

Objetivo: Sistema operativo ligero para microcontroladores (ESP32, Raspberry Pi Pico) que funciona como sistema "kiosk" con gestión de aplicaciones vía API.

Características Principales:

  • Lenguaje y Entorno:
    • MicroPython: Python para microcontroladores
    • Microdot: Microframework para la API
  • Compatibilidad:
    • ESP32, Raspberry Pi Pico y otros
  • Sistema Kiosk: Interfaz simplificada para ejecución controlada de aplicaciones
  • Gestión de Apps:
    • Instalación/actualización remota vía API
    • Repositorio centralizado
  • Seguridad:
    • Aislamiento de aplicaciones
    • Verificación de integridad

Aplicaciones:

  • Dispositivos IoT
  • Kiosks y terminales de autoservicio

Futuras Expansiones:

  • Soporte para más hardware
  • Interfaz gráfica ligera
